Install Lunaway with F-Droid

Lunaway publishes its own F-Droid repository: an Android version without any Google service, kept up to date by the F-Droid app.

Add the repository and install the app

  1. Install F-Droid from f-droid.org, if you do not have it yet.
  2. On your phone, open the repository link above, or scan its QR code: F-Droid offers to add the repository. Otherwise, in F-Droid, open Settings, then Repositories, tap + and paste the repository address.
  3. Check that the fingerprint F-Droid shows is the one on this page.
  4. Search for "Lunaway" in F-Droid and install the app. Updates then come through F-Droid.

Good to know

  • This version is built without Google Play services: location goes straight through Android.
  • The Google Play version and the version of this repository are not signed with the same key, and Android refuses to replace one with the other. To switch, uninstall the app first; favourites kept only on the device go with it.
  • The code of every version is on GitHub, under the AGPL.

Without Android, the web app runs in the browser.
