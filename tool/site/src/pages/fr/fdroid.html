Installer Lunaway avec F-Droid

Lunaway publie son propre dépôt F-Droid : une version Android sans aucun service Google, mise à jour par l'app F-Droid.

--- main

Le dépôt

Adresse du dépôt
https://lunaway.net/fdroid/repo
Empreinte de la clé (SHA-256)
EA3E C0CA 3EF9 7A4F 9E31 552D 3875 1AEA CCE2 02A2 D15C D5FB B318 F20E DE91 0D2B
Lien pour le téléphone
Ajouter le dépôt Lunaway à F-Droid

Ajouter le dépôt et installer l'app

  1. Installez F-Droid depuis f-droid.org, si vous ne l'avez pas encore.
  2. Sur votre téléphone, ouvrez le lien du dépôt ci-dessus, ou scannez son QR code : F-Droid propose d'ajouter le dépôt. Sinon, dans F-Droid, ouvrez Paramètres, puis Dépôts, touchez + et collez l'adresse du dépôt.
  3. Vérifiez que l'empreinte affichée par F-Droid est celle de cette page.
  4. Cherchez « Lunaway » dans F-Droid et installez l'app. Les mises à jour arrivent ensuite par F-Droid.

Bon à savoir

  • Cette version est construite sans les services Google Play : la position passe directement par Android.
  • La version de Google Play et celle de ce dépôt ne sont pas signées par la même clé, et Android refuse de remplacer l'une par l'autre. Pour changer de version, désinstallez d'abord l'app ; les favoris gardés seulement sur l'appareil partent avec elle.
  • Le code de chaque version est sur GitHub, sous licence AGPL.

Sans Android, l'app web fonctionne dans le navigateur.
