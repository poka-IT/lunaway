Das Projekt

Lunaway hilft Ihnen zu finden, wo Sie mit dem Wohnmobil oder dem Van haltmachen können: Ver- und Entsorgungsstationen, Parkplätze, Campingplätze, Stellplätze auf dem Bauernhof, Plätze in freier Natur, Wasser- und Entsorgungsstellen. Die Plätze decken Frankreich und zwanzig weitere europäische Länder ab, und die App spricht Französisch, Englisch, Deutsch, Spanisch, Italienisch und Niederländisch.

Die App ist kostenlos, ohne Werbung und ohne Tracker, und wir verkaufen keine Daten. Sie wird von AxiomTeam herausgegeben, und ihr Code ist freie Software.

Sie besteht aus einer Flutter-App (Android, iPhone und iPad, macOS, Windows und das Web), einer in Rust geschriebenen API auf PostgreSQL und PostGIS und unseren eigenen Servern bei Hetzner in Deutschland, die auch die Grundkarte ausliefern, die Routen berechnen und die Adresssuche sowie die Übersetzung der Rezensionen übernehmen. Jeder Platz vereint, was mehrere Quellen über denselben Ort sagen, und bewahrt für jede Angabe die Quelle, die sie geliefert hat.

Quellen und Namensnennung

Lunaway stützt sich auf offene Daten, auf die Beiträge seiner Community und auf eine externe Community-Quelle, mit der eine schriftliche Vereinbarung besteht. Jede Platzseite zeigt ihre Quellen, mit ihrer Lizenz, der ursprünglichen Kennung und dem Datum der Erhebung.

Lunaway importiert eine proprietäre Datenbank mit Plätzen, Rezensionen oder Fotos nur auf Grundlage einer schriftlichen Vereinbarung mit ihrem Hersteller. Die externe Community-Quelle ist die einzige in diesem Fall; ihre Daten gelangen weder in die offene Datenbank der Plätze noch in deren Exporte. Ein Datenbankhersteller, der seine Daten unter einer Lizenz anbieten möchte, kann uns schreiben.

Lizenzen

  • Code der App, des Servers und dieser Website: GNU AGPL-3.0-or-later.
  • Datenbank der Plätze, einschließlich neuer Plätze und Änderungen: ODbL 1.0. Sie enthält Daten von OpenStreetMap und ist damit eine abgeleitete Datenbank, die unter derselben Lizenz veröffentlicht wird. Die Werte der externen Community-Quelle gehören nicht dazu.
  • Rezensionen und Fotos der Lunaway-Community: CC BY 4.0, mit Nennung des Pseudonyms ihres Autors.
  • Schriften dieser Website: Fraunces von Undercase Type (SIL Open Font License 1.1) und Atkinson Hyperlegible Next vom Braille Institute (SIL Open Font License 1.1), auf lateinische Zeichen reduziert. Die zweite ist die Variante der App, mit einer Null ohne Schrägstrich.
  • Symbole: Phosphor (MIT-Lizenz).

Mitmachen

  • In der App: Bewerten Sie einen Platz, bestätigen Sie mit „Noch da?“, dass es ihn noch gibt, melden Sie ein Problem, schreiben Sie eine Rezension, fügen Sie ein Foto oder einen Platz hinzu, melden Sie während der Navigation ein Problem auf der Straße. Ein neues Konto kann bewerten, bestätigen und melden; Rezensionen und Fotos werden nach drei Tagen und drei bestätigten Plätzen freigeschaltet, das Hinzufügen von Plätzen nach zwei Wochen und zehn veröffentlichten Beiträgen. Diese Stufen halten Spam fern, ohne nach einer E-Mail-Adresse zu fragen.
  • In OpenStreetMap: Eine Korrektur auf openstreetmap.org erreicht Lunaway mit dem nächsten Import und hilft allen freien Karten.
  • Im Code: Melden Sie einen Fehler oder schlagen Sie eine Verbesserung auf GitHub vor.

Quellcode
