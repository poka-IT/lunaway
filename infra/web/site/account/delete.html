Supprimer votre compte Lunaway

Lunaway, l'app de cartes pour camping-cars et vans publiée par AxiomTeam, vous permet de supprimer votre compte et ses données à tout moment, de deux façons.

1. Dans l'app

Ouvrez Profil, puis, sous Votre compte, Supprimer mon compte. L'app montre ce qui sera supprimé et ce qui restera ; touchez Continuer, cochez « Je comprends que c'est définitif », puis touchez Supprimer le compte. L'app doit être connectée à internet. La suppression est immédiate, et les contributions qui attendaient encore d'être envoyées sont effacées de l'appareil.

2. Sur cette page, avec votre code de secours

Si vous n'avez plus l'appareil, utilisez le code de secours que l'app vous a donné quand vous avez créé votre carte de secours.

Supprimer le compte avec le code de secours

27 lettres et chiffres, par groupes de quatre, comme sur votre carte (les tirets et les espaces sont facultatifs).

Saisissez votre code de secours.

Un code de secours compte 27 lettres et chiffres, sans les tirets ; ce code en compte 0.

Le caractère «  » n'apparaît jamais dans un code de secours.

Ce code contient une faute de frappe : comparez-le caractère par caractère avec votre carte.

Ce formulaire a besoin de JavaScript. Sans lui, supprimez votre compte depuis l'app, ou écrivez-nous.

Confirmer la suppression

Vous allez supprimer le compte Lunaway lié à ce code :

La suppression est immédiate et définitive : le compte ne pourra pas être rétabli.

Votre compte est supprimé

Le compte lié à ce code n'existe plus, et les données listées ci-dessous ont été supprimées. Les sauvegardes chiffrées en gardent une copie 30 jours environ.

Un appareil qui utilisait ce compte n'y a plus accès : si vous contribuez de nouveau depuis lui, l'app créera un nouveau compte.

Aucun compte ne correspond à ce code

Le compte a peut-être déjà été supprimé, ou un code plus récent a remplacé celui-ci : créer un nouveau code de secours dans l'app annule le précédent. Vérifiez le code sur votre carte, ou supprimez le compte depuis l'app.

Trop d'essais pour le moment

Pour protéger les comptes, notre serveur accepte 5 essais de code de secours par heure depuis une même connexion. Réessayez dans 60 minutes.

Ce code n'est pas reconnu

Le serveur ne l'accepte pas comme code de secours. Comparez-le caractère par caractère avec votre carte.

La demande n'a pas abouti

Le serveur n'a pas répondu, ou a répondu par une erreur, et rien ne dit si le compte a été supprimé. Réessayez dans quelques minutes : si le compte n'existe plus, cette page vous l'indiquera. Si le problème continue, écrivez à contact@lunaway.net.

Sans l'appareil ni le code

Le compte n'est lié à aucune adresse e-mail ni à aucun numéro de téléphone : sans l'appareil ni le code de secours, rien ne permet de prouver qu'un compte est le vôtre. Écrivez-nous quand même à contact@lunaway.net, et nous chercherons une solution avec vous.

Ce qui est supprimé

Tout de suite, en une seule opération :

  • le compte lui-même : pseudonyme, niveau de confiance, dates d'activité ;
  • les clés de vos appareils, toutes vos sessions et votre code de secours ;
  • vos listes de favoris enregistrées sur le serveur, avec les adresses et les points que vous y aviez enregistrés ;
  • les auteurs que vous aviez masqués, et les masquages qui visaient votre compte ;
  • toutes vos photos, fichiers compris ;
  • vos notes sans texte, et ceux de vos avis qui n'étaient pas publiés ;
  • vos réponses « toujours là ? » sur les commerces et services ;
  • vos signalements de problème sur un lieu, et vos signalements d'avis, de photos ou de lieux ;
  • vos propositions de lieu ou de modification qui attendaient un modérateur ;
  • les clés techniques de vos contributions.

Sur l'appareil, vos favoris restent, détachés du compte, et la clé du compte est effacée.

Ce qui reste, sans votre nom

Certaines contributions sont publiques sous licence ouverte et servent aux autres voyageurs. Elles restent, détachées de votre compte :

  • vos avis publiés avec un texte (texte, note, date de visite, véhicule), affichés comme venant d'un « compte supprimé » ;
  • vos confirmations « toujours là ? » des lieux, sans la note que vous y aviez jointe ;
  • vos ajouts de lieux ou de distributeurs et vos modifications déjà traités, avec leur contenu et leur position : appliqués, ils font partie de la base ouverte des lieux (ODbL) ; refusés ou retirés, ils restent dans l'historique des révisions.

Pour qu'un avis disparaisse aussi, supprimez-le dans l'app avant de supprimer votre compte.

Délai

La suppression est immédiate dans notre base de données. Les sauvegardes chiffrées de la base et des photos en gardent une copie 30 jours environ, puis l'effacent (le détail est dans la politique de confidentialité) ; elles ne servent qu'à remettre le service en marche après une panne, et une sauvegarde remise en service ne ramène pas un compte supprimé : la suppression, notée dans un journal à part (l'identifiant du compte et l'heure, 45 jours au plus, copié chaque nuit avec les sauvegardes), est appliquée de nouveau. Seule la perte du disque de données du serveur lui-même ramènerait les suppressions faites après la dernière copie recueillie hors de ce serveur (jusqu'à 25 heures environ).

Supprimer une seule contribution

Sans supprimer votre compte, vous pouvez supprimer dans l'app, depuis Profil, Mes contributions, chacun de vos avis et notes, chacune de vos photos, de vos confirmations, de vos réponses sur les commerces et services, de vos signalements de problème, et chacune de vos propositions de lieu.

  • Un avis ou une photo est effacé pour de bon. S'il avait été signalé ou masqué par la modération, son texte ou ses fichiers sont effacés et il disparaît de l'affichage, mais une ligne reste pour la modération (la note, pour un avis), liée à votre compte jusqu'à sa suppression.
  • Une proposition de lieu pas encore appliquée est retirée et ne sera jamais appliquée ; elle reste dans l'historique des révisions, liée à votre compte jusqu'à la suppression de celui-ci. Un ajout ou une modification déjà appliqué reste dans la base des lieux, sans votre nom.

Une question

Écrivez à contact@lunaway.net. La politique de confidentialité détaille toutes les données de Lunaway.
