# CTranslate2 int8. A pair without its own model goes through English.

# models towards French scored above the Firefox Translations models,

# helped, German to French and French to English, the two pairs most
# reviews need.
#
# Towards German, Spanish, Italian and Dutch, the app's other languages: a
# bilingual model for each pair that has one, at the base size, the release
# whose scores in the README beside the archives are the highest or level
# with them; transformer-big for French to German alone, French being the
# language of most reviews. Italian to Dutch has only a multilingual model
# (itc-gmw, which needs a target token the server does not write), Dutch to
# Italian none: both go through English.
